## 简介

军队编制编辑器是一个完全运行在浏览器里的单文件 HTML 工具。你可以像搭积木一样拖动兵牌、调整部队归属、编辑装备人数，实时看到整支部队的树状编制结构和统计汇总。

无需安装，无需登录，打开网页就能用。数据全部保存在你自己的浏览器里。

---

## 功能特性

### 编辑
-  **拖拽调整编制**：拖动兵牌到其他单位上收编，或调整同级顺序
-  **拖到左侧兵牌库**即可删除单位
-  **每个单位可独立切换**横向 / 纵向排列
-  **智能自动编号**：营、连、排、班自动按规则编号，师直属单位自动命名为「师直属XX营」

### 兵牌
-  **北约军标风格**：基于 FM 1-02.2 / MIL-STD-2525E 标准绘制
-  **36 种默认兵牌**：涵盖机动、火力、航空、保障四大类
-  **自定义兵牌**：自由组合主元素 + 上方修饰 + 下方属性，拼出你自己的兵种
-  **双主题**：正常 / 暗黑，兵牌配色跟随主题切换

### 数据
-  **本地保存**：存档保存在浏览器 localStorage
-  **导入导出文件**：可将编制导出为 `.json` 文件，或从文件加载
-  **导出图片**：一键导出完整编制树为 JPG 图片，方便分享

### 预设
-  装甲师 · 步兵师 · 机械化步兵师（默认）
-  第101空中突击师（现代美军）
-  陆战第1师（二战美军）
-  大德意志装甲师（二战德军）
-  第88师（抗战国军德械师）
-  空白师

### 交互
-  完整键盘快捷键（Ctrl+C/V/Z、Space 折叠、Del 删除、方向键导航等）
-  兵牌库支持分类筛选和关键词搜索
-  无限画布：滚轮缩放、空白处拖动平移
-  移动端适配：底部抽屉、长按拖拽、双指捏合缩放
-  30 步撤销栈
